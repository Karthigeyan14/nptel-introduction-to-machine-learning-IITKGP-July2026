# NPTEL – Introduction to Machine Learning

## IIT Kharagpur | NPTEL

This repository contains the **8-week assignments and solutions** from the NPTEL course **Introduction to Machine Learning**, offered by **IIT Kharagpur**.

The repository is created for **learning, revision, and NPTEL examination preparation**.
